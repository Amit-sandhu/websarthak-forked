# WebSarthak — Creative Agency Website

A multi-page React + Vite website for WebSarthak, styled as a dark editorial creative studio.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite (usually http://localhost:5173).

## Pages
- Home
- Services
- Web Development
- Social Media Marketing
- Work / Portfolio
- About
- Pricing
- Contact
- FAQ

## Visual direction
The interface is built from scratch around the supplied creative references: oversized editorial typography, black and purple atmospheric backgrounds, thin grid textures, neon-lime accents, asymmetrical photographic compositions, campaign imagery, browser mockups and phone-frame social previews. The supplied reference screenshots are **not** used as page content or embedded in the site.

Photography currently loads from Unsplash URLs, so an internet connection is required to display those images. Replace the sample photography with licensed client/project images before publishing. Portfolio entries are illustrative concept work, not claims about completed client projects.

## Functionality notes
- React Router page navigation
- Responsive mobile navigation
- Portfolio and service navigation
- Contact inquiry form currently uses browser-side demo handling; connect an email/form backend before launch
- Pricing and FAQ interactions are frontend-only

## Production checklist
1. Replace illustrative campaign photography with original/licensed assets.
2. Connect the contact form to an email service or backend.
3. Replace placeholder contact details and social links.
4. Add analytics, SEO metadata, and deployment environment settings.
